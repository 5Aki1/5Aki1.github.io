---
title: EUbar
---

```bash
pip install eubar
```

EUbar treats ChIP-seq signal across DNase-accessible regions as an in vivo binding array. It scores every 8-mer by the signal of the regions that contain it, and uses those scores to predict how a variant changes transcription factor binding.

- Code: [github.com/SvenBaileyLab/EUbar](https://github.com/SvenBaileyLab/EUbar)
- PyPI: [pypi.org/project/eubar](https://pypi.org/project/eubar/)
