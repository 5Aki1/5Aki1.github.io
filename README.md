# 5aki1.github.io

Personal site of Eftyhios (Aki) Kirbizakis, built with [Quartz](https://quartz.jzhao.xyz).

- Write pages in `content/` (open it as an Obsidian vault). Blog posts go in `content/notes/`.
- Preview locally: `npm ci && npx quartz build --serve`, then open http://localhost:8080
- Publish: commit and push to `main`. GitHub Actions builds and deploys.
